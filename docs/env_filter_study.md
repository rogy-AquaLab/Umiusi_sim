# 実映像から測った会場フィルタは、初見の濁ったプールで効くか（2026-10-06）

## 結論（先出し）

- **フィルタを掛けた sim を実画像に混ぜる（条件 C）と、未見の 10/03 run で F1 0.09 → 0.65**（2 seed とも）。黄は再現率 0.05 → 0.82。
- **同じフィルタを実画像に掛ける（B / D）のは効かない**か、C の効きを打ち消す。
- 代償: 自プール pool2_val が 0.64 → 0.56（−0.08）。JAMSTEC 保留は変わらない（0.43 → 0.42）。
- 10/03 のもう一方の run（144510、遠く淡い青だけ）はどの条件も 0.1〜0.2 で改善なし。
- **conf 0.4 では全条件とも 10/03 でほぼ 0**。濁りの中では信頼度が上がらないので、運用の閾値は 0.3 が要る。
- 10/03 の画像は学習に 1 枚も入れていない。フィルタの参照に使ったのは 151920 以外の run の生フレーム（ラベル不使用）。

## フィルタ（`tools/env_filter.py`）

参照フレーム 1 枚ごとに 32x32 の低周波画像（濁りの色・上下の色むら・周辺減光）、帯域 2〜8 px のコントラスト、
1 px 帯域のコントラストを測って bank に貯める。掛けるときは対象画像の同じ量が参照に揃うよう透過率 t とぼけ σ を選ぶ
（`out = t·img·tint + (1−t)·veil` → ガウスぼけ）。画素は動かないので箱はそのまま。

| 参照 | 枚数 | 重み | 帯域 2〜8 px | 1 px 帯域 |
|---|---|---|---|---|
| p1003（10/03、151920 以外の run） | 155 | 2 | 0.87 | 0.49 |
| p0913（9/13 プール） | 120 | 1 | 5.25 | 2.31 |
| jam（他チーム JAMSTEC） | 120 | 1 | 3.90 | 1.66 |

見本 `data/envfilt/demo.jpg`（列: 元 / jam ×2 / p0913 ×2 / p1003 ×2）。

学習側は `tools/perception_train.py` の opt-in 引数: `--env-filter bank.npz`（実画像に確率 `--env-filter-prob` で
`_underwater` の代わりに掛ける）、`--sim-prefix sim_pool/`（この前置きの画像は必ずフィルタ、`_underwater` は掛けない）、`--seed`。
指定しなければ従来どおり。

## 条件

共通: `examples/balloon_detector/model.pt` から 120 epoch、lr 5e-4、batch 8、input 256、threads 4。seed 0 / 1。

| 条件 | 学習データ | フィルタ |
|---|---|---|
| A | `poolmix2_otrgb_train`（実 1242 枚） | なし |
| B | 同上 | 実画像の 50% |
| C | 実 1242 + `sim_pool` 無作為 500（`envfilt_mix_train.json`） | sim のみ（常時） |
| D | 同上 | sim 常時 + 実画像 50% |

評価は `umiusi_perception.eval` と同じ照合（IoU≥0.3、色一致）。10/03 の GT は `ai/balloon/pool1003/annotations/val{151920,144510}.json`
（151920: 青 91 / 黄 99、近い風船。144510: 青 43、遠く淡い）。赤はこの日無いので red の検出は全部誤検出（重りなど）。

## 読み方

- 効いたのは「10/03 の見え方 × 近くて大きい風船」で、sim_pool（近い風船が多い）にフィルタを掛けたものがちょうどそれになる。
  144510 の遠く淡い青は、どの条件でも拾えない。
- 実画像にフィルタを掛けると悪くなる理由の見立て: 9/13 の実画像は 10/03 参照に合わせると t ≈ 0.17（下限 0.15 付近）まで薄められ、
  風船がほぼ消えるのに箱は残る。sim は元のコントラストが高いので同じ t でも風船が残る。実画像側は t の下限か揺らぎを上げる必要がある（未検証）。
- 自プールの −0.08 は sim の混入と同じ傾向（`sim_pool_appearance.md` の C と同じ）。sim の割合や参照の重みで調整できるかは未検証。
- seed 2 本で順位は一致。差 0.5 は seed 差（0.0〜0.1）より十分大きい。

## 残リスク・次に試すこと

1. 実画像側の t 下限を上げる（0.15 → 0.3〜0.4）か、実画像にはぼけと色むらだけ掛けてベールを弱める。
2. sim の枚数（250 / 500 / 1000）と参照の重みで、自プールの低下と 10/03 の改善の折り合いを測る。
3. 本命は F320 なので、C を input 320 で学習して 10/03・JAMSTEC を測る。
4. 会場で使う手順: 到着後の数分の映像から `env_filter build` → sim_pool に掛けて混ぜて再学習（CPU で約 2 時間）。
   10/03 のデータが無い状態を再現した今回の結果は、その手順の見積もりに相当する。
5. 重りの赤誤検出（151920 で 24〜40）はフィルタでは減らない。負例（10/03 の重りフレーム）を入れるか、FSM 側で赤の閾値を分ける。
